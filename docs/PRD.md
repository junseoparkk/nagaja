# nagaja PRD

## 1. 서비스 개요

| 항목      | 내용                                                        |
| --------- | ----------------------------------------------------------- |
| 서비스명  | nagaja (나가자)                                             |
| 도메인    | nagaja.kr                                                   |
| 한줄 설명 | 8개 질문으로 나의 예상 퇴사일을 계산해주는 직장인 공감 웹앱 |
| 타겟      | 20~30대 직장인                                              |
| 목적      | SNS 바이럴을 통한 팔로워 확보 + 포트폴리오                  |
| 배포      | Vercel (무료)                                               |

---

## 2. 문제 정의

기존 번아웃 테스트와의 차이점:

- 기존: "당신은 번아웃 상태입니다" → 진단으로 끝
- nagaja: "당신의 예상 퇴사일은 2026년 8월 14일" → **날짜**가 나온다

---

## 3. 핵심 목표

- 웃기고 재밌어야 함
- 공감가야 함
- 현실을 어느정도 반영해야 함
- 결과 카드를 SNS에 공유하고 싶어져야 함

**성공 지표 (4주 기준)**

| 지표                | 목표     |
| ------------------- | -------- |
| 누적 테스트 완료 수 | 1,000회  |
| SNS 공유 수         | 200회    |
| 재방문율            | 15% 이상 |

## 6. 유저 플로우

```
랜딩 (/)
  ↓ [시작하기] 클릭
Q0: 이름 입력
  ↓ 입력 후 [시작하기] or [건너뛰기]
Q1~Q7: 퇴사 욕구 질문 (점수 누적)
  ↓
Q8: 성향 분기 질문
  ↓
/loading?score=14&tendency=creative&name=김철수

/result?type=danger&name=김철수
  ↓
사직서 카드 렌더링 + 공유
```

## 7. Q0 이름 입력 스펙

**UI:**

```
"본격적으로 시작하기 전에
이름을 알려주세요"

[_______________]
placeholder: "닉네임도 OK"
최대 글자수: 10자

[건너뛰기 →]  [시작하기 →]
```

**동작 규칙:**

- 이름 입력 + 시작하기 → name 저장 후 Q1으로
- 건너뛰기 → name = null, Q1으로
- 엔터키 → 시작하기와 동일
- 프로그레스바 미표시 (질문 시작 전)
- 서버 저장 없음, 로컬에서만 사용

## 9. 점수 계산

```
Q1~Q7: 각 0~3점 → 최대 21점
Q8: 성향 분기만 (점수 미반영)
총점: 0~21점
```

**점수 → 퇴사 욕구 %:**

```
Math.min(Math.round((score / 21) * 99), 99)
```

## 10. 유형 분기 로직

```
총점 0~7   → 모범사원형 (성향 무관)
총점 19~21 → 전설의퇴사형 (성향 무관)

총점 8~18 + 성향 조합:
  creative (창업형):
    8~13  → 제주도카페사장형
    14~18 → 이미탈출한형

  transfer (이직형):
    8~13  → 만년이직준비형
    14~18 → 사직서7개보유형

  escape (현실도피형):
    8~13  → 조용한퇴사형
    14~18 → 번아웃말기형

  noplan (무계획형):
    8~13  → 무계획퇴사형
    14~18 → 통장이붙잡는형
```

## 11. 결과 유형 10가지

### 🟢 모범사원형 (model)

- 퇴사 욕구: 5~15%
- 예상 퇴사일: 2029년 이후
- 사직서 사유: "본인은 아직 회사에 희망을 품고 있습니다. 월급날 설레고, 야근도 성장이라 생각합니다. 팀원들이 '쟤는 왜 저래'라고 수군거리고 있으나 본인은 인지하지 못하고 있습니다."
- 공유 카피: "나만 정상인 거 맞지?"

### 🌴 제주도카페사장형 (jeju)

- 퇴사 욕구: 45~58%
- 예상 퇴사일: 올해 하반기
- 사직서 사유: "본인은 회의 중 창업 아이템을 3개 이상 검색한 경험이 있으며, 제주도 카페 창업 비용을 엑셀로 정리해둔 파일이 바탕화면에 존재합니다. 파일명은 '카페창업계획*진짜최종*수정2.xlsx'입니다."
- 공유 카피: "제주도 카페 사장 될 사람 🙋"

### ✈️ 이미탈출한형 (escaped)

- 퇴사 욕구: 88~95%
- 예상 퇴사일: 이번 주
- 사직서 사유: "본인은 퇴사 후 계획을 이미 수립하였으며 노션에 창업 로드맵이 37페이지 작성되어 있습니다. 주변인들에게 '나 곧 퇴사해'를 말한 지 6개월이 지났습니다. 이번엔 진짜입니다."
- 공유 카피: "이번엔 진짜 퇴사함 (6번째)"

### 📋 만년이직준비형 (jobhopper)

- 퇴사 욕구: 52~65%
- 예상 퇴사일: 면접 붙는 날
- 사직서 사유: "본인은 현재 이력서를 17번째 수정 중이며, 링크드인 프로필을 '구직 중'으로 설정한 지 8개월이 지났습니다. 서류는 항상 붙고 면접에서 탈락하는 패턴이 반복되고 있으나 원인은 불명입니다."
- 공유 카피: "이직 준비 중인 척만 3년째"

### 📁 사직서7개보유형 (resume7)

- 퇴사 욕구: 72~82%
- 예상 퇴사일: 3개월 이내
- 사직서 사유: "본인의 바탕화면에는 사직서 초안이 현재 7개 저장되어 있습니다. 파일명: 사직서*초안1.hwp ~ 사직서*최종진짜.hwp. 모두 날짜만 다를 뿐 내용은 동일합니다. 오늘 드디어 제출합니다."
- 공유 카피: "사직서 7개 보유 중 📁"

### 🕵️ 조용한퇴사형 (quiet)

- 퇴사 욕구: 48~60%
- 예상 퇴사일: 언젠가는
- 사직서 사유: "본인은 이미 6개월 전부터 퇴사 상태입니다. 몸만 출근 중이며, 시키는 것만 하고 칼퇴 후 본인의 진짜 삶을 살고 있습니다. 회사 입장에서는 재직 중, 본인 입장에서는 이미 없음."
- 공유 카피: "조용히 퇴사 중인 사람 ✋"

### 🔥 번아웃말기형 (burnout)

- 퇴사 욕구: 82~91%
- 예상 퇴사일: 이번 달
- 사직서 사유: "본인은 현재 출근 중이지만 뇌 활동은 최소한으로 유지되고 있습니다. 회의 중 딴생각 비율이 94%에 달하며, 오늘 점심 뭐 먹을지가 분기 목표보다 중요하게 느껴집니다."
- 공유 카피: "번아웃 말기 환자입니다 🏥"

### 🎲 무계획퇴사형 (noplan)

- 퇴사 욕구: 55~68%
- 예상 퇴사일: 욱하는 날
- 사직서 사유: "본인은 구체적인 퇴사 계획이 없으나 충분히 욱하면 낼 수 있는 상태입니다. 통장 잔고는 확인하지 않았으며, '어떻게든 되겠지'를 3년째 반복 중입니다."
- 공유 카피: "계획은 없고 욱은 있음"

### 💸 통장이붙잡는형 (wallet)

- 퇴사 욕구: 75~85%
- 예상 퇴사일: 적금 만기일
- 사직서 사유: "본인의 퇴사를 막고 있는 유일한 존재는 월급통장입니다. 마음은 이미 나갔으나 고정지출이 본인을 매달 붙잡고 있습니다. 월세, 카드값, 구독료가 공범입니다."
- 공유 카피: "퇴사하고 싶은데 월세가..."

### 💀 전설의퇴사형 (legend)

- 퇴사 욕구: 99%
- 예상 퇴사일: 오늘
- 사직서 사유: "팀장님, 저 잠깐 드릴 말씀이 있는데요. 본인은 이 테스트의 모든 문항에서 가장 극단적인 선택지를 골랐습니다. 이것은 테스트가 아니라 고백입니다. 지금 이 화면을 캡처해서 단톡방에 올리십시오. 그것이 본인의 사직 의사 표명입니다."
- 공유 카피: "팀장님 저 잠깐요... 🚪"

## 16. 타입 정의

```typescript
export type Tendency =
  | "creative" // 창업형
  | "transfer" // 이직형
  | "escape" // 현실도피형
  | "noplan"; // 무계획형

export type ResultType =
  | "model" // 모범사원형
  | "jeju" // 제주도카페사장형
  | "escaped" // 이미탈출한형
  | "jobhopper" // 만년이직준비형
  | "resume7" // 사직서7개보유형
  | "quiet" // 조용한퇴사형
  | "burnout" // 번아웃말기형
  | "noplan" // 무계획퇴사형
  | "wallet" // 통장이붙잡는형
  | "legend"; // 전설의퇴사형

export interface QuizState {
  name: string | null;
  currentQ: number; // 0 = 이름입력, 1~8 = 질문
  answers: number[];
  tendency: Tendency | null;
  totalScore: number;
}

export interface ResultData {
  type: ResultType;
  pct: number;
  grade: string;
  gradeDesc: string;
  stampText: string;
  subject: string;
  reason: string;
  quitDate: string;
  shareComment: string;
}
```
